BeatWave, redesigned for every age

One engine and one project format, three experience layers — Explorer (pre-readers to ~8), Studio (9 and up), Pro (power users) — all on a single design system with dark and light themes. Each screen below is annotated; the small notes under each screen name the gaps it closes (F# features, N# functions, A# activities, P# performance) from 2026-11-07-gap-audit-all-ages.md. Use the Light / Dark button above. The Explorer screens keep their own warm palette in both themes.

Rules

  1. Roles, not hexes. Screens read tokens; dark, light, high-contrast and Explorer are four token sets (gap F6).
  2. Instrument colour is data. Drums coral, bass amber, synth cyan, vocal pink — on notes, pills, mixer strips and thumbnails, so a project can be read at a glance.
  3. One glow = live. Only the playhead, the play button and the selected track glow. Nothing else competes.
  4. Targets: 48 dp minimum in Studio/Pro, 64 dp in Explorer; row height 28 dp is allowed only inside the grid where a note is larger than its cell (gap N8).
  5. Motion: 120–220 ms ease-out for state, spring for pads; the playhead is drawn, not recomposed; everything honours “reduce motion” (gap P2).
  6. Haptics: tick on place, double-tick on delete, soft thud on a pad.
  7. Radius: 10 / 16 / 24 (Studio), 16 / 24 / 36 (Explorer). Elevation by tint first, shadow second.

Studio — melodic and drum grids

Same screen skeleton; the body changes with the track's kind.

  1. Track pills own a full-width row (just shipped) and carry the instrument colour + sound name.
  2. Tool row: Record, Sounds, key/scale, tempo — each ≥ 48 dp, scrolls if the screen is narrow (N8, N9).
  3. Undo / redo in the app bar — the safety net for every age (F8).
  4. Note names + key. Rows read C5, Eb5, G4 with the root in the accent colour; out-of-scale rows are dimmed, not hidden (F10, N13).
  5. Loop brace on the ruler (drag to set bars), plus a loop toggle and a metronome in the transport (F9).
  6. Playhead is drawn in the draw phase and the view follows it past the edge (N6, P2).
  7. Go-to-start button and a tappable ruler replace seek-by-tiny-strip (N7).
  8. Drum lanes use real icons + names, 16 steps a bar, accent-ringed current step; swing and tempo in the tool row.

Sound library v2 & the note editor

Left: browse by kit with pictures, preview by tapping. Right: select a note and a bottom sheet appears — no hidden long-press.

  1. Search + category chips + kits with art. The old alphabetical list of 8 becomes a browsable library (F4, N14).
  2. Tap the play button to hear it before choosing; waveform and root key shown on each row (F3, F10).
  3. “Use” replaces “Add/Remove” wording; a check mark shows what the track already uses.
  4. Selecting a note opens a bottom sheet, not a modal dialog — volume, fine-tune, length, octave, copy, duplicate-bar, delete. A selection ring marks the note; the velocity lane sits under the grid (N1, F11).
  5. Pitch changes can’t hide another note — if the target row is taken the sheet says so (shipped as a guard; this is its UI).
  6. Delete is in the sheet and undoable with a “Note deleted · Undo” snackbar (F8).

Mixer and recording

The “professional” layer: per-track control, loudness you can see, and a recording flow that explains itself.

  1. Channel strips: pan knob, fader, live level meter, mute/solo, in the instrument's colour (F7).
  2. Master with a limiter and a loudness meter — you see −13.8 LUFS against a −14 streaming target, and the clip warning that the old always-on soft-clip hid (P10).
  3. Record screen: big elapsed time, ring progress, live input meter with a plain verdict (“healthy”), live waveform (F9).
  4. Count-in and click make takes land in time; after the take, a ✓ keeps it and a bin discards it (N3).
  5. Headphone tip prevents speaker bleed — the single biggest cause of bad first recordings.
  6. Mic permission dead-end fixed: if the system dialog was denied twice this screen replaces it with “Microphone is off — open Settings” and a button that jumps there (N2).

Export

A share card people actually post, and an export that does not freeze the app.

  1. Share card with waveform and title — a pretty thing to send, not a bare file (A10, F15).
  2. Format as a segmented control: small AAC for messaging, WAV 24-bit for producers (F16).
  3. Loudness targets with an honest readout of peak after limiting (P10, DSP-8).
  4. Progress ring, cancel, and background export — no more locked engine during a long render (P8).
  5. Done card persists so the share isn't lost if you leave the screen.

Explorer — pads, pattern, celebrate

Three screens: free play, make a pattern, you did it.

  1. Pads are the entry. Four big pads (drums, bass, keys, voice); a tap plays instantly and the pad presses down. Cause and effect in under a second (F3, A2).
  2. Pictures, not words, with a talking speech bubble; tapping it reads the line aloud (needs strings externalized — F14).
  3. Pattern strips: 8 big squares per instrument, snapped to a grid so everything sounds in time; the current step lifts as it plays.
  4. Slower 🐢 / faster 🐇 instead of a BPM number.
  5. Celebrate making, not returning. Stars reward creating; there are no streaks, timers or loss messages (§6 guardrail).
  6. Again · Change · Keep — a child can never lose work; “Keep” saves to Music and it opens in Studio.
  7. No recording, no import, no share unless a guardian turns them on (F17).

Activities hub & Copy the Beat

The tool becomes a place to play. Filter by level; every activity is the same grid underneath.

  1. One list, filtered by level (All ages · Little · Maker · Producer), so a family sees things for everyone (A1–A12).
  2. Copy the Beat: hear a pattern, rebuild it, get kind feedback — “6 of 8 match”, never “wrong” (A3).
  3. Hints, not penalties. Hint reveals one step; there is no failure state and no timer.
  4. Melody Maker and Voice Instrument reuse key lock and recording — the engine work is shared (A7, A8).
  5. Pro challenges keep adults engaged with real goals (−14 LUFS, odd time signatures) (A12).

Settings & guardian gate

One place for appearance, accessibility and the controls that protect younger users.

  1. Experience layer is a setting, not an age question — the app never asks a child how old they are (F1).
  2. Appearance & access in the first screen: theme, large text, high contrast, reduce motion (F6, Access band).
  3. Guardian PIN guards mode, microphone, import, share. A PIN, not a maths puzzle a bright 8-year-old can solve; reset uses the device lock (F17).
  4. Microphone, import and share default OFF in Explorer; ON in Studio/Pro (§8 compliance checklist).
  5. Privacy in plain words — and true: the app has no network code (verified).

Large text · high contrast · screen reader

The same screen at 1.5× text with 56 dp targets, and a pure high-contrast token set.

  1. Large text reflows, never clips: rows scroll, the header never squeezes the track row (shipped for pills) (N9, N10).
  2. 56 dp targets in the large preset; the transport grows with it (N8).
  3. High-contrast tokens — black/white/yellow with outlines instead of glows; notes keep their shape and a heavy outline so colour is never the only signal.
  4. Focus ring in the accent colour for keyboard, D-pad and Switch Access (GAP1-V1).
  5. TalkBack reads position and pitch — “Filled, Eb5, bar 2 beat 1 step 1” (shipped; now with note names) and long notes can be created without dragging (GAP1-5) (N15).
  6. Reduce motion freezes glows, meters and the playhead sweep to a stepped indicator.

Tablet / unfolded Fold — Pro layout

Three panes: tracks · grid · inspector. This is the deferred two-pane grid, grown into a real workspace.

  1. Track list is a column, with mute/solo on every row and a key colour for each instrument (F7, F19).
  2. The grid gets the whole centre: 8 bars visible, a velocity lane underneath, a loop brace on the ruler, 32 columns at once (P2/P3 need the virtualized canvas first).
  3. Inspector on the right shows the selected note and master loudness — no modal, no sheet.
  4. Transport spans the bottom with tempo, loop and metronome within reach of the thumbs.
  5. Adapts by window size, not device name: the same layout appears in a split-screen window or on a desktop-mode display; on the closed Fold's cover screen it collapses to the phone layout from §3.
  6. Keyboard & stylus: arrows move, Enter places, Space plays; S Pen hover shows the note name before you touch (GAP1-V1).

What this is, and isn't

These are static design mockups — a proposal and a vocabulary for the redesign, not working UI. Colours, spacing and copy are first drafts; the emoji in the Explorer layer stand in for custom illustrations. Nothing has been tested with children or educators. Build order and dependencies are in the gap audit (§10): trust the audio first, then the design system, undo, audition and strings, then the layers.
